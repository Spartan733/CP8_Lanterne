# Prérequis

Les prérequis techniques minimaux sont :
- D'avoir un compte vercel
- D'avoir Node.js de version 18 ou plus
- D'avoir installer la CLI vercel (npm i -g vercel)
- D'avoir une connexion a GitHub


# Installation locale
## Installation de la CLI de Vercel
Utilisation de la commande 
```Node
npm i -g vercel

```
